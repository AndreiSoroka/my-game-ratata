# Прошлое героя и начальные возможности

Предыстория выбирается при создании личности. Правила и интерфейс используют
`contracts/src/backgrounds.ts`: общую человеческую основу 30 HP / 100 энергии /
40 маны и постоянные прибавки. Смена управления и обычное воскрешение
не назначают бонусы повторно.

| Прошлое  | Прибавка HP / энергия / мана | Начальные HP / энергия / мана | Ускоренное мастерство      |
| -------- | ---------------------------- | ----------------------------- | -------------------------- |
| Авангард | +20 / +20 / 0                | 50 / 120 / 40                 | Клинок +20%                |
| Следопыт | +10 / +20 / 0                | 40 / 120 / 40                 | Стрела +20%                |
| Арканист | 0 / 0 / +30                  | 30 / 100 / 70                 | Магия +20%                 |
| Клирик   | 0 / 0 / 0                    | 30 / 100 / 40                 | Все молитвенные школы +20% |

В бою класс не меняет базовый урон, геометрию обычной атаки, её темп и стоимость,
скорость движения или критический шанс. Изученные звёзды и текущее оружие
применяют собственные общие модификаторы. Начальные знания, способности
и созвездия сохраняются. Клирик начинает с Воскрешением. Следопыт начинает
с Быстрым и Снайперским выстрелами. Быстрый назначен на вторую ячейку,
а Снайперский доступен в списке для назначения на панель.

`awardMasteries` суммирует награды одного действия, затем применяет
`базовый опыт × бонус прошлого × коэффициент конфликта`, округляя один раз
до микроопыта. Конфликт хранится отдельной величиной. Повторный receipt
не добавляет опыт; золото, вещи и общий опыт персонажа не умножаются.
Расчёт атласа использует ту же функцию `backgroundMasteryRewardMicros`.

Прибавки ресурсов складываются с основной конфигурацией до процентных
модификаторов звёзд. Окно персонажа показывает постоянные бонусы отдельно
от наблюдений нынешнего здоровья и сил. Выбор прошлого дополнительно
показывает исходные запасы до звёзд.

Знания жителей находятся в статье `knowledge/development/backgrounds.md`.
Её численные утверждения проверяются по общим определениям. Актуальная
вместимость и состояние чужого тела из этой статьи не выводятся.

Целевые проверки:

```sh
bun run --cwd apps/backend test tests/background-bonuses.test.ts tests/mastery-progression.test.ts
bun run test:e2e -- e2e/join-background.spec.ts e2e/character-window.spec.ts
```
