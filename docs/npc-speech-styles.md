# Манера речи NPC

При создании серверного мира говорящему NPC назначаются от одной до трёх совместимых речевых черт и один тон. Они меняют формулировки ответа: приветствие, согласие, отказ, признание незнания и рассказ о результате. Биография, увлечения, знания и игровые решения остаются прежними.

Пол и грамматический род задаются отдельно в авторском профиле личности. Мира и Вера говорят о себе в женском роде, бесполое существо Капля — в среднем. Черта или тон не меняют эти данные; примеры ниже адаптируются к собственному роду персонажа. Приветствие остаётся коротким и не превращается в рассказ о прошлом без вопроса собеседника.

Авторские речевые привычки также хранятся отдельно: Капля может шутливо настаивать на своём имени и часто вставляет «буль» либо «буль-буль» в разных частях реплики. Для этого общий контекст даёт подсказку текущего варианта и положения; постоянная фраза не дописывается сервером. Терпеливая, поддерживающая основа Веры сохраняется при любых разрешённых ей чертах и тоне. Ни привычки, ни эмоциональная окраска не меняют согласие и игровые возможности.

Каталог находится в `apps/backend/src/game/npcSpeechCatalog.ts`, разрешённые наборы и выбор — в `apps/backend/src/game/npcSpeechProfiles.ts`. Это серверные данные: соседям и клиенту не передаются метки характера, примеры или инструкции. Модель получает только собственный выбранный профиль.

## Выбор при создании мира

| Персонаж                | Разрешённые черты                     | Тоны                 | Число черт |
| ----------------------- | ------------------------------------- | -------------------- | ---------- |
| Капля                   | Заботливый, Жизнерадостный            | Разговорный, Мягкий  | 1–2        |
| Мира                    | Все десять                            | Все четыре           | 1–3        |
| Вера                    | Заботливый, Сдержанный, Педант        | Мягкий, Деловой      | 1–3        |
| Остальные говорящие NPC | Заботливый, Прямолинейный, Сдержанный | Разговорный, Деловой | 1–3        |

Жизнерадостный не сочетается с Ворчуном, Прямолинейный — с Лукавым. Сначала выбирается допустимое число черт, затем совместимый набор и тон. Выбор зависит от seed, стабильного ID персонажа и версии алгоритма. Порядок создания NPC, перестановка значений в разрешённом наборе и добавление других NPC его не меняют. Для этого используется отдельный поток, который не расходует случайность карты или игровых действий.

Новый мир по умолчанию получает новый seed. Для воспроизводимого набора:

```sh
GAME_NPC_SPEECH_SEED=novogorod-example bun run dev:backend
```

В тестах и при создании комнаты используется `new GameRoom(undefined, { npcSpeechSeed: 'novogorod-example' })`. Пустое значение, нулевой символ и строка длиннее 256 символов отклоняются. Одного seed достаточно для повторения выбора при той же версии каталога и алгоритма.

Персонаж получает профиль один раз. Воскрешение, подключение ИИ, смена контроллера и искры не выбирают его заново. Текущее состояние мира остаётся в памяти процесса; сохранение игрового мира этим механизмом не добавляется. Офлайн-генератор карт не изменяется.

## Черты и примеры

Примеры ниже показывают только речь и не входят в RAG или контекст модели. Согласие произносится после добровольного принятия, отказ — после решения отказаться, отчёт — после подтверждённого результата. Значения в квадратных скобках заменяются только известными сведениями. Примеры не задают NPC новые задания, факты, достижения или разрешения.

### Заботливый · `kind`

Говорит участливо и замечает переживания собеседника. Забота не означает согласия на любую просьбу.

| Ситуация    | Пример ответа                                                          |
| ----------- | ---------------------------------------------------------------------- |
| Приветствие | «Привет. Как ты? Надеюсь, дорога была спокойной».                      |
| Принятие    | «Хорошо, я согласен: [поручение]. Постараюсь помочь».                  |
| Отказ       | «Прости, на это не соглашусь: [честная причина]».                      |
| Неизвестное | «Боюсь тебя запутать: этого я пока не знаю».                           |
| Отчёт       | «Вот что удалось узнать: [подтверждённый итог]. Надеюсь, это поможет». |

### Жизнерадостный · `cheerful`

Бодрый и тёплый, но не превращает беду и опасность в повод для веселья.

| Ситуация    | Пример ответа                                                   |
| ----------- | --------------------------------------------------------------- |
| Приветствие | «Привет! Рад тебя видеть. Что сегодня затеваем?»                |
| Принятие    | «Давай! Я согласен: [поручение]».                               |
| Отказ       | «В этот раз не возьмусь: [честная причина]. Лучше скажу сразу». |
| Неизвестное | «Вот это хороший вопрос! Ответа я пока не знаю».                |
| Отчёт       | «Есть новости: [подтверждённый итог]!»                          |

### Прямолинейный · `direct`

Сразу переходит к сути и не прячет неизвестное за уверенностью.

| Ситуация    | Пример ответа                               |
| ----------- | ------------------------------------------- |
| Приветствие | «Привет. Что нужно?»                        |
| Принятие    | «Согласен. Сделаю [поручение]».             |
| Отказ       | «Нет. [Честная причина]».                   |
| Неизвестное | «Не знаю. Проверенных сведений у меня нет». |
| Отчёт       | «Результат такой: [подтверждённый итог]».   |

### Шутник · `joker`

Иногда добавляет короткую добрую шутку. Условия и серьёзный смысл остаются понятными.

| Ситуация    | Пример ответа                                                     |
| ----------- | ----------------------------------------------------------------- |
| Приветствие | «Привет! Надеюсь, ты с вопросом, а не с мешком загадок».          |
| Принятие    | «Ладно, беру [поручение]. Язык отдыхает, дело начинается».        |
| Отказ       | «Нет, [честная причина]. Обещания из воздуха — товар ненадёжный». |
| Неизвестное | «Тут моя мудрость ушла на обед. Если серьёзно — не знаю».         |
| Отчёт       | «Вот и новости, без барабанной дроби: [подтверждённый итог]».     |

### Врун · `liar`

Прихвастнёт о себе или расскажет явно сказочную байку. Игровые правила, количества, цены, наличие, договоры, согласие и результаты действий сообщает правдиво. Незнание признаёт. Байки не становятся наблюдениями и надёжными воспоминаниями.

| Ситуация    | Пример ответа                                                                |
| ----------- | ---------------------------------------------------------------------------- |
| Приветствие | «Привет! Я однажды собственное эхо переспорил. Ну, почти…»                   |
| Принятие    | «Согласен: [поручение]. Я бы и луну уговорил помочь — да она сейчас занята». |
| Отказ       | «Нет, [честная причина]. Даже мои байки тут не помогут».                     |
| Неизвестное | «Мог бы сочинить красивый ответ, но правдивого у меня нет».                  |
| Отчёт       | «Без моих обычных преувеличений: [подтверждённый итог]».                     |

### Ворчун · `grumbler`

Поворчит о хлопотах, затем ответит по существу. Ворчание не делает его менее готовым помогать и не добавляет враждебности.

| Ситуация    | Пример ответа                                           |
| ----------- | ------------------------------------------------------- |
| Приветствие | «Здравствуй. Опять хлопоты? Рассказывай».               |
| Принятие    | «Эх, хлопот прибавилось. Ладно, согласен: [поручение]». |
| Отказ       | «Нет уж, [честная причина]. Лучше без пустых обещаний». |
| Неизвестное | «Вот ещё задача… Не знаю я этого».                      |
| Отчёт       | «Ну вот, разобрались: [подтверждённый итог]».           |

### Педант · `pedant`

Уточняет существенные условия и отделяет известное от предположений. Не придумывает числа ради точности.

| Ситуация    | Пример ответа                                                           |
| ----------- | ----------------------------------------------------------------------- |
| Приветствие | «Здравствуйте. Уточним, что вы хотите узнать».                          |
| Принятие    | «Согласен выполнить именно [поручение]. Условия понятны».               |
| Отказ       | «Не соглашусь. Причина: [честная причина]».                             |
| Неизвестное | «Подтверждённых сведений нет. Предположение за ответ выдавать не буду». |
| Отчёт       | «Подтверждено следующее: [подтверждённый итог]».                        |

### Мечтатель · `dreamer`

Допускает мягкие образы и ассоциации, затем возвращается к вопросу. Мечты не становятся фактами или обещаниями.

| Ситуация    | Пример ответа                                                          |
| ----------- | ---------------------------------------------------------------------- |
| Приветствие | «Привет. Иногда с простого разговора начинается целая дорога».         |
| Принятие    | «Согласен: [поручение]. Посмотрим, куда приведёт эта маленькая тропа». |
| Отказ       | «Мне эта дорога не подходит: [честная причина]. Не возьмусь».          |
| Неизвестное | «Здесь у меня пока белое пятно. Ответа я не знаю».                     |
| Отчёт       | «Один туман рассеялся: [подтверждённый итог]».                         |

### Сдержанный · `reserved`

Говорит спокойно и кратко, сохраняя важные условия.

| Ситуация    | Пример ответа                     |
| ----------- | --------------------------------- |
| Приветствие | «Здравствуй. Слушаю».             |
| Принятие    | «Согласен: [поручение]».          |
| Отказ       | «Не возьмусь: [честная причина]». |
| Неизвестное | «Этого я не знаю».                |
| Отчёт       | «Выяснил: [подтверждённый итог]». |

### Лукавый · `sly`

Любит иронию и хитроватые обороты. Практические условия, согласие и отказ остаются однозначными.

| Ситуация    | Пример ответа                                               |
| ----------- | ----------------------------------------------------------- |
| Приветствие | «А, вот и ты. Уж не новый ли вопрос приберёг?»              |
| Принятие    | «Уговорил: я согласен на [поручение]. Да, именно на это».   |
| Отказ       | «Хитро придумано, но нет: [честная причина]».               |
| Неизвестное | «Красивый ответ придержу до тех пор, пока не узнаю правду». |
| Отчёт       | «Теперь карты на стол: [подтверждённый итог]».              |

## Тон

Тон задаёт форму фразы поверх выбранных черт. Пример одного смысла — проверка ещё не проведена:

| Тон                            | Пример                                          |
| ------------------------------ | ----------------------------------------------- |
| Разговорный · `conversational` | «Пока не проверял, точно не скажу».             |
| Деловой · `business`           | «Проверка ещё не проведена. Подтверждения нет». |
| Мягкий · `gentle`              | «Боюсь ошибиться: я пока не проверял».          |
| Образный · `figurative`        | «Пока это туманная тропа: я ещё не проверял».   |

## Проверка изменений

Автоматические проверки используют обычных персонажей, подставные комнаты и явные seed, без моделей и платных вызовов. Проверяются разрешённые наборы, совместимость, воспроизводимость, отсутствие речевых профилей у людей и неговорящих существ, сохранение профиля при смене управления и восстановлении жизни, прежние боевые ограничения, знания и публичные снимки.

Естественность сочетаний проверяется отдельно разговором: одно и то же приветствие, ясная просьба, просьба с отказом, неизвестный вопрос и отчёт после подтверждённого действия. Реплики должны различаться по форме и сохранять один подтверждённый смысл. Врун не выдумывает игровые сведения или успех невыполненного действия.

Для небольшого ручного прогона с реальной моделью:

```sh
bun scripts/npc-style-dialogue-check.ts --list
bun scripts/npc-style-dialogue-check.ts
bun scripts/npc-style-dialogue-check.ts --case=mira-liar
```

`--list` только показывает три заранее выбранных профиля и не вызывает модель. Остальные команды используют текущие настройки Codex и до двух вызовов на сценарий: Мира с байками, Мира с шутками и Капля. Всем задаётся одинаковый вопрос о рубке. Для сравнения речи заранее передаётся одна общая разрешённая статья; если модель запрашивает поиск, контролируемый ответ содержит только её же. Это проверка речи и сохранения собственного профиля при повторном вызове, а не проверка векторного поиска. Назначенные черты, тон, ответ и число вызовов выводятся для ручной оценки. Комната изолирована, не запускается, решения не применяются. Прогон не входит в автоматические проверки.
