# Устаревшие хранилища

В `stores/` остался демонстрационный счётчик Pinia из стартового шаблона Vue. Не добавляйте сюда хранилища и не создавайте зависимости от этого каталога.

Размещайте общее для слайса состояние в его `model/`. Локальное состояние держите рядом с потребителем. Истории Storybook `*.stories.ts` размещайте рядом с соответствующими компонентами.
