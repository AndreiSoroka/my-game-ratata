# Shared

Общий фундамент приложения по FSD: переиспользуемые библиотеки, UI и интеграции без предметной игровой логики. Shared не зависит от `game` или других прикладных слоёв. Потребители используют публичный API соответствующего модуля или группы UI.

Размещайте `*.stories.ts` рядом с компонентом Shared в его модуле. В последнем сегменте `title` указывайте точное имя файла `.vue` без расширения. Экспортируйте `Default` первым и управляйте его состоянием через публичные параметры компонента и примеры слотов. Правила Controls и изоляции компонента описаны в разделе Storybook корневого `AGENTS.md`.
