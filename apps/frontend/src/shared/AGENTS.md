# Shared

Общий фундамент приложения по FSD: переиспользуемые библиотеки, UI и интеграции без предметной игровой логики. Shared не зависит от `game` или других прикладных слоёв; потребители используют public API конкретного модуля.

Размещайте `*.stories.ts` рядом с компонентом Shared в его модуле. В последнем сегменте `title` указывайте точное имя файла `.vue` без расширения. Используйте примеры данных, которые можно передать через публичный API компонента.
