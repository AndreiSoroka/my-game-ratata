# Common UI

Общий интерфейс для игры может использовать компоненты из `external`. Внутри Shared импортируйте из публичного API конкретного компонента. Для остальных слоёв экспортируйте компоненты через `@/shared/ui/common`.

Для полос используйте `BarTrack` для подложки, `BarFill` для заполнения и `GameBar` для готовой полосы. Схемы ресурсов и общие цвета находятся в `theme`. Значения и разрешённую точность передаёт вызывающий код.
