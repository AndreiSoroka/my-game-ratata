# Common UI

Общий интерфейс для игры; может брать основу из `external`. Используйте public API конкретного компонента и не добавляйте зависимости от игровых модулей.

Для полос используйте `BarTrack` и `GameBar`; схемы ресурсов и общие цвета находятся в `theme`. Значения и разрешённую точность передаёт вызывающий код, оформление и состояния принадлежат компонентам.
