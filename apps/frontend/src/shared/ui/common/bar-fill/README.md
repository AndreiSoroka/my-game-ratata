# BarFill

`BarFill` рисует цветную часть полосы. Импортируйте компонент и `BarFillProps`
через `@/shared/ui/common/bar-fill`.

`color` принимает CSS-цвет, включая переменные и `currentColor`. По умолчанию
используется `lightUiColors.bar.health.color`. Высота `height`
задаётся в CSS-пикселях и по умолчанию равна 24, минимальная высота равна 8.
`shadow` включает симметричную внутреннюю кромку и по умолчанию равен `true`.

Корневой `span` принимает обычные атрибуты, классы и стили. Ширина по умолчанию
занимает доступное место. Подложку можно добавить через `BarTrack`, а готовую
полосу со значением и доступной подписью предоставляет `GameBar`.
