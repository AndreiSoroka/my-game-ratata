# Shared UI

Общие компоненты интерфейса и визуальные основы приложения без игровых правил. Импортируйте компоненты и тему через их собственные `index.ts`, без общего barrel-файла для всего UI.

Общий интерфейс игры находится в `common`, готовые кнопки — в `common/button/UiButton`; сторонние ассеты и их обёртки держите в `external`. Общая палитра находится в `theme`; состояние наведения, нажатия и disabled принадлежит компоненту, а не его потребителям.
