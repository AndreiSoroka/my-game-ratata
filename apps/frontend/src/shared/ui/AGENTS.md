# Shared UI

Общие компоненты интерфейса и визуальные основы приложения без игровых правил. Код за пределами Shared импортирует через `@/shared/ui/common`, `@/shared/ui/external` и `@/shared/ui/theme`. Внутри Shared используйте `index.ts` конкретного компонента или темы.

Общий интерфейс игры находится в `common`, готовые кнопки — в `common/button/UiButton`; сторонние ассеты и их обёртки держите в `external`. Общая палитра находится в `theme`; состояние наведения, нажатия и disabled принадлежит компоненту, а не его потребителям.
