# Игровой клиент

В `game/` находятся игровой рантайм, сцены Excalibur, обработка ввода и адаптеры, которые связывают игровой сеанс с интерфейсом. Существующие компоненты поддерживайте в рамках их текущих обязанностей.

Не добавляйте новые UI-компоненты в `game/`. Доменные и экранные компоненты размещайте в `ui/` слайса-владельца, а общие примитивы — в `shared/ui/`. Подключайте их к игровому сеансу через адаптеры и пользуйтесь публичным API слайсов.
