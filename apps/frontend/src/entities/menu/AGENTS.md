# Menu

MenuPanel оформляет переданные пункты, управляет их порядком и фокусом и отдаёт ID действия наверх. Адаптеры клавиатуры и геймпада вызывают публичный `navigate(command)`; привязки устройств, игровые команды, звук и управление глобальными окнами остаются снаружи. Используйте Shared через public API.
