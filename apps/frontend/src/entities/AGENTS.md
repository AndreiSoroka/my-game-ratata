# Entities

Сущность описывает понятие предметной области. В `model` находятся предметные данные, состояние и правила, в `ui` — компоненты, которые представляют эту сущность. Собирайте их из компонентов Shared и экспортируйте через публичный API слайса. Игровые команды, привязка к игровому сеансу и владение окнами остаются в адаптерах приложения.

У каждого UI-компонента сущности должна быть своя история в Storybook. Размещайте `*.stories.ts` рядом с компонентом. Используйте `Entities/<слайс>/<ИмяКомпонента>`, где имя точно совпадает с именем файла `.vue` без расширения.
