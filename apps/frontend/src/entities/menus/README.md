# MenuPanel

Готовое меню с кофейной поверхностью, простой внешней рамкой `015` и внутренней двойной ступенчатой рамкой `014`. Между рамками — 10 px. Кнопки используют `UiButton` с орнаментом `026`, прозрачной заливкой и смысловой палитрой при подсветке.

```vue
<script setup lang="ts">
import { MenuPanel, type MenuItem } from '@/entities/menus'

const items: readonly MenuItem[] = [
    { id: 'resume', label: 'Вернуться в игру', variant: 'primary' },
    { id: 'character', label: 'Персонаж', key: 'P' },
    {
        id: 'leave',
        label: 'Выйти из игры',
        variant: 'danger',
        dividerBefore: true,
    },
]
</script>

<template>
    <MenuPanel :items="items" @action="handleAction" />
</template>
```

`MenuItem` содержит `id`, `label` и необязательные `key`, `variant`, `disabled`, `ariaLabel`, `pressed`, `hint`, `dividerBefore`. Компонент отдаёт единственное событие `action(id)` и не исполняет игровые команды. `title` и `description` можно переопределить. Клавиша выводится текстом после названия.

`dividerBefore: true` добавляет перед произвольным пунктом `FantasyDivider` варианта `000` с завершениями с двух сторон, без затухания. Он расположен по центру, занимает 70% ширины кнопки и имеет непрозрачность 60%. Разделитель не перехватывает ввод и не участвует в порядке фокуса. Игровой адаптер использует его перед выходом.

Потребитель задаёт ширину. CSS-переменная `--menu-panel-max-height` ограничивает высоту; прокручивается содержимое внутри обеих рамок. При управлении мышью подсветка сохраняется через промежутки между пунктами и гаснет при выходе из списка. Реальный фокус клавиатуры управляет подсветкой отдельно; клик не закрепляет выбранный пункт.

Публичный `MenuPanelHandle.navigate(command)` принимает `previous`, `next`, `first`, `last` или `activate`. Меню само выбирает доступные пункты, пропускает `disabled` и циклически перемещает нативный фокус. Начальный `next` выбирает первый доступный пункт, `previous` — последний. `activate` вызывает действие только действительно сфокусированного доступного пункта этого меню; фокус снаружи или наведённый курсором пункт не подменяет выбор. При смене данных используется текущий порядок отрисованных пунктов. Метод возвращает `true`, если фокус установлен или действие вызвано, иначе `false`.

Клавиатура и геймпад используют один и тот же метод через ref типа `MenuPanelHandle`. Команды не зависят от клавиш, кнопок контроллера или частоты его опроса. Программная навигация передаёт подсветку управляемому фокусу и очищает прежнее наведение мышью.

Игровой адаптер сохраняет внешний нативный диалог, `data-dialog-action`, начальный фокус, Escape и владение вводом. Он переводит W/S, стрелки, Tab и подтверждение в команды меню; будущий адаптер геймпада подключается к этому же API. Stories находятся в `Entities/Menus/MenuPanel`; браузерные скриншоты запускаются вручную.
