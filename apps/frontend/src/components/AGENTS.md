# Устаревшие компоненты

Здесь остались демонстрационные компоненты и тест из стартового шаблона Vue. Не добавляйте сюда компоненты и не используйте этот каталог в новом коде.

Размещайте компоненты в `ui/` того слайса, который ими владеет, а общие примитивы — в `shared/ui/`. Истории Storybook `*.stories.ts` храните рядом с соответствующими компонентами.
