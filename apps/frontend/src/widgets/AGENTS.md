# Widgets

Виджет связывает входные данные и компоненты в самостоятельный блок интерфейса. Из других слайсов он использует логику и компоненты только через публичные API слоёв `shared`, `entities` и `features`. Виджет обходится без собственных стилей. Внешнее размещение задаёт экран, внутреннее оформление принадлежит компонентам нижележащих слоёв.

Размещайте `*.stories.ts` рядом с компонентом виджета в его слайсе. Используйте `Widgets/<слайс>/<ИмяКомпонента>`, где имя точно совпадает с именем файла `.vue` без расширения. Передавайте примеры данных через публичные пропсы виджета. Интеграционные истории игрового адаптера размещайте рядом с самим адаптером.
